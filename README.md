# AegisResponse — Disaster Management & Tactical Emergency Coordination

A high-contrast red-black-white tactical disaster command, live sector map, and emergency resource allocation platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Tactical Sector Map & Pin Dropping**: Interactive sonar radar canvas with animated pulsing markers for active floods, wildfires, and structural breaches.
- **Incident Severity & Triage**: Comprehensive tracking of affected population, assigned field units, and required vs fulfilled emergency supplies.
- **Relief Supply Logistics Board**: Real-time warehouse stockpile status for trauma surgical kits, mobile water purification units, and satellite uplinks with live field dispatch actions.
- **Emergency Alert System (EAS) Broadcaster**: Push emergency flash broadcasts across civilian, field tactical, and hospital channels.
- **Real-Time Incident Logger**: Duty commanders can register new crisis hotspots with severity classifications and sector coordinates.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3042`
